# 护眼小助手（QuizGate）使用说明

> 适用设备：夏普 LCD-45T45A（Android 4.4.4）
> 产物：`build/QuizGate.apk`（约 32 KB）

## 这是什么

孩子看电视时，每隔一段时间自动弹出一道小学题目，**连对 2 题才能继续看**。

默认六年级，语文 / 英语 / 数学三科轮转。

不是管控工具，是提醒工具——原因见文末「已知限制」。

## 安装

```bash
adb connect <TV_IP>:5555
adb install -r build/QuizGate.apk
```

或者用 U 盘 + 当贝市场安装。

## 使用

1. 电视应用列表里打开 **护眼小助手**（绿色圆形图标）
2. 三个按钮：
   - **开始监控** / 停止监控
   - **间隔**：1 / 5 / 10 / 15 / 30 分钟循环切换（默认 5 分钟）
   - **年级**：1~6 年级循环切换（默认 6 年级）
3. 点「开始监控」，**设置界面会立刻关闭**回到桌面，之后自动运行

> 说明：点开始监控后界面立即消失是刻意设计。否则每次做完题，界面会重新弹出来，
> 而不是回到孩子原本在看的画面。

想停止监控：重新打开图标 →「停止监控」。

## 开机自启

**已实现。** 前提是至少点过一次「开始监控」（该状态会保存）。

之后每次开机，`BootReceiver` 会收到 `BOOT_COMPLETED` 广播并拉起服务。

实测记录（2026-11-01）：

| 项 | 结果 |
|---|---|
| 重启电视后 adb 自动重连 | ✅（`persist.adb.tcp.port=5555`）|
| 服务是否自动启动 | ✅ 进程 pid 变化，日志有 `service created` |
| 开机后是否按间隔弹题 | ⚠️ 75 秒观察窗口内未弹，疑因开机后系统加载占用了较长时间 |

**结论：开机自启的"服务启动"这一环确认可用；"开机后首次弹题"的时机会比开机时间点延后，
具体延后多久未做严格测量。** 日常使用（开机后看视频）不受影响，因为间隔是连续观看累计的。

## 做题界面怎么操作

- 遥控器**方向键**在 4 个选项间移动，**确认键**提交
- 答对：计数 +1，换下一题
- 答错：显示解题思路，3 秒后换题，**计数归零**
- 连对达到要求（默认 2 题）→ 自动关闭，**回到做题之前你正在看的画面**

## 孩子会怎么试图绕过，以及实测效果

| 尝试 | 实测结果 |
|---|---|
| 按遥控器「返回」键 | ✅ 被吞掉，界面不动 |
| 按「Home」键 | ✅ 被抢回（服务每 3 秒复查一次焦点），**答题进度不再重置** |
| 断电重启 | ⚠️ 若已开启监控则自动恢复，但计数从零开始 |
| 系统设置里强行停止应用 | ❌ 拦不住 |
| 卸载应用 | ❌ 拦不住 |

## 题目范围

默认六年级，**语文 / 英语 / 数学三科轮转**（每轮打乱顺序，保证三科均衡）。

| 科目 | 题型 | 题量 | 题源 |
|---|---|---|---|
| **数学** | 百分数、四则混合、比例、数列（等差/等比/平方数）、应用题 | 无限 | 模板 + 随机参数生成，背不下来 |
| **语文** | 古诗接句、成语释义、近反义词、修辞、错别字、**唐诗宋词（16）**、**国学经典（12）**、**历史（12）**、**地理（13）** | 75 | 知识表，洗牌袋抽取，一轮内不重复 |
| **英语** | 词义互译、be 动词、时态、介词搭配、名词复数、比较级、日常问答 | 20 | 同上 |

数学题干扰项按「常见错误」构造（差一、错一步、反向运算），不是随机数。
每题都带解析，答错时显示知识点。

## 测试

### 单元测试（不需要电视）

```bash
bash tests/unit/run_unit.sh 500 6
```

纯 JVM 跑题库，覆盖：

- 结构：选项必须 4 个、答案下标合法、选项不重复、题干非空
- **正确性：数学题用独立求解器反算，必须与答案选项一致**
- 分布：三科都出现且大致均衡
- 稳定性：大批量生成不抛异常
- 无连续重复

实测：400 题、4933 条断言、数学 133 题全部核验通过、0 失败。

### 端到端测试（需要电视）

```bash
python tests/e2e/e2e_test.py
```

在真机上跑完整链路，覆盖 8 项断言：

| 编号 | 验证点 |
|---|---|
| T1 | 默认配置正确（5 分钟 / 6 年级 / 语英数）|
| T2 | 点开始监控后设置界面消失 |
| T3 | 到点自动弹出做题界面 |
| T4 | 返回键不退出做题界面 |
| T5 | 答对达标后自动放行 |
| T5b | 放行后不再回到设置界面 |

测试脚本会从 `QuestionBank.java` 源码解析题库，因此**能自动答对所有语文英语题**。

实测：8/8 通过。

## 已知限制

1. **不是管控，是提醒。** 系统设置里能强行停止应用、能卸载。真拦住需要系统级权限
   （Device Owner），Android 4.4 没有这个能力。
2. **不保存错题历史**，没有家长数据面板。
3. **开机后首次弹题的时机不确定**（见上文）。
4. 答错会重置连对计数。若发现孩子反复失败僵持，可把 `Prefs.getNeedCount()` 默认值改成 1。

## 重新编译

工具链已备好（JDK 8 + JDK 17 + build-tools 35 + android-4.4.2），不需要 Gradle：

```bash
export TVGUARD_KEYSTORE=/path/to/your.jks
export TVGUARD_KS_PASS=yourpassword
bash build/build.sh
```

六步：aapt 生成 R.java → javac(JDK8, `-source 1.7`) 编译 → d8 转 dex →
aapt 打包 → zipalign → jarsigner 做 **v1 签名**（4.4 只认 v1）。

签名文件不随仓库分发，需自备（`keytool` 命令见 README）。
换密钥会导致无法覆盖安装。

## 自动化入口（测试用）

主界面支持通过 Intent 传参直接设定状态，方便脚本化测试：

```bash
adb shell am start -n com.tvguard.tutor/.MainActivity \
  --ei tvguard.interval 1 --ez tvguard.autostart true
```

支持的参数：`tvguard.interval`(int)、`tvguard.grade`(int)、
`tvguard.running`(bool)、`tvguard.autostart`(bool)。
`autostart` 走的是和点「开始监控」完全相同的代码路径。
